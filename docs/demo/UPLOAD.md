# Demo upload

The final MP4 is four minutes long, with English captions burned into the image.
`upload-metadata.json` contains the prepared title, description and chapter times.
`speech-contrast-demo.en.srt` provides the same captions as a separate track.

Upload the MP4 to an existing YouTube channel and choose **Unlisted**, not Private.
Use the prepared title and description. The intended audience is technical judges
and developers; the video is not made for children. No paid promotion or
monetization is requested. Copy the playable YouTube watch URL into the Devpost
video field after processing finishes.

The demo contains real UI captures and explicitly labeled DSP edits of public-domain
speech. It contains no generated voice, fabricated speech or generated video.
OpenAI Codex's production assistance is disclosed in the description. YouTube's
[AI disclosure guidance](https://support.google.com/youtube/answer/14328491)
distinguishes production assistance and captions from realistic generated media.
